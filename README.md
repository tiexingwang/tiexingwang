## 🚀 Featured Project

### 🧠 [Transformer from Scratch (PyTorch)](https://github.com/tiexingwang/Transformer_from_scratch)

A **complete Transformer architecture implementation** built from the ground up using PyTorch:

- ✅ Encoder, Decoder, Multi-Head Attention, Positional Encoding  
- 🧪 100% unit test coverage with `pytest`  
- 🔍 Validated against `torch.nn.Transformer` for correctness  
- 📚 Educational explanations for every component  
- 🎯 Memory-efficient and modular design  

**Key Features:**  
- Explicit dimension handling in multi-head attention  
- Causal masking for decoder blocks  
- Cross-attention between encoder and decoder  
- Extensive test suite validating math correctness  

📌 **Goal**: Serve as both a **learning resource** and a **portfolio project** demonstrating engineering skills and deep learning fundamentals.
